Convert to a ProPresenter playlist

SlideBridge builds a ProPresenter playlist from this week's files, in the look of a playlist you already finished, so the songs, readings and sermon slides come out in your usual style. Any one file is enough.

Worship script Recommendedoptional
PDF:
PDF files only (.pdf). The order of service, Nats Panggilan, Bible reading and the full lyrics of every song.
PowerPoint decks Recommendedoptional
Sermon deck:
PowerPoint files only (.pptx). The preacher's deck: each slide becomes a slide in the playlist.
Master deck:
PowerPoint files only (.pptx). The master deck from Church Center, used as the template: it fills in what the script does not have, such as the date. If a song's motion is not on this computer, that song's background picture is taken from this deck.

SlideBridge looks in ProPresenter's standard folder by default. If you moved or renamed your ProPresenter workspace, choose that folder here: it is the one with Libraries and Playlists inside. SlideBridge only reads it and never changes it. Without ProPresenter on this computer, open a .proplaylist file instead.
